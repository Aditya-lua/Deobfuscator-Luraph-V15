Command line

Prefer the terminal, or need to batch a folder? The engine is a self-contained CLI.

Install

git clone https://github.com/Aditya-lua/Deobfuscator-Luraph-V15
cd Deobfuscator-Luraph-V15
# bin/luau ships prebuilt; rebuild if needed:
python3 build_luau.py

Run

# one file
node deob.js payload.lua -o clean.luau

# just detect the version
node deob.js payload.lua --detect

# a whole folder
node deob.js ./scripts/

Useful flags

--detect        print version, don't run
--no-devirt     behaviour trace only
--timeout 180   per-run wall-clock cap (s)
--strings       aggressive string decode
